W124 SOCIETY INDIA — COMMUNITY PLATFORM PROTOTYPE
===================================================
This is a multi-page, locally stored static website prepared from the attached master prompt.

DEPLOY TO THE EXISTING NETLIFY SITE
1. Extract this ZIP on your Mac.
2. Keep index.html, all .html pages, styles.css, script.js, assets/, robots.txt and sitemap.xml together.
3. Open https://app.netlify.com/ and select the existing site with URL:
   https://guileless-blancmange-9961e3.netlify.app/
4. Open Deploys and use the manual deploy / drag-and-drop upload area.
5. Upload the extracted W124_India_Community_Platform folder to the existing site.
6. Wait for the deploy to finish, then open the existing URL and test navigation.

IMPORTANT HONEST LIMITATIONS
- This is a static front-end prototype, not a full-stack community.
- Registry sample cards are fictional and labelled demonstration data.
- Contribution form validates in the browser but does not submit or store data.
- No real owners, live posts, specialist businesses, prices or events are invented.
- All bundled vehicle visuals are AI-generated illustrations, not photographs of actual cars.
- Detailed variant-specific technical facts and repair procedures require further verification.
- External Team-BHP links are for reference; their content and images are not copied into the website.

FILES
- 14 HTML pages: home, heritage, registry, garage, technical library, community, events,
  directory, market watch, stories/gallery, contribute, sources/about, guidelines, privacy.
- styles.css: responsive design, navigation, tables, forms and cards.
- script.js: mobile navigation, demo registry filters and honest prototype form behaviour.
- assets/: locally stored generated image assets.
- sitemap.xml and robots.txt.
